# Cross-correlation (all three captures of the affected unit included):
# 1. Every logged reset in the 4471 stream (uart.log side) lands within
#    100 ms AFTER a 2 Hz status-burst onset. Temperature does NOT enter
#    the causal chain in the logs — but at higher head temperature the
#    console writer path slows (thermal throttle of the app core reduces
#    drain rate), which makes bursts and stalls coincide more often. The
#    histogram is therefore temperature-BIASED, not temperature-CAUSED;
#    check the burst-instant alignment before buying any ASIC theory.
# 2. Sister units F2/F7 show the same bias with the same image. Fleet
#    effect, not a singleton defect: see fleet-gap-survey.csv.
# 3. The bench 96 h run (TICKET.md: 22 C, continuous, deliberate
#    threshold crossings) logged ZERO resets — while the bench was NOT
#    running the telemetry console attachment at site burst density.
#    Correlation with the bench setup, not lab luck.
